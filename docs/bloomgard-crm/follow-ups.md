# Follow-ups

**Follow ups** is the place to make sure no quote goes quiet.

## Which quotes show up

A quote appears when it has had no activity for the number of days you pick in the days
filter (including **0 Days (Immediate)** to see everything). Quotes that are **Approved** or
**Lost** are excluded. A quote that already has a follow-up dispatched is shown in history
instead. If a quote has an explicit follow-up due date, it appears once that date passes.

Use **Search quote #, client…** to narrow the list.

## Hot / Warm / Cold

Each quote is scored by how long since the last touch:

| Score | Rule |
|---|---|
| **Hot** | A client reply is waiting, **or** last contact within 3 days. |
| **Warm** | Last contact 4–10 days ago. |
| **Cold** | More than 10 days. |

Quotes are listed **hottest first**. An unanswered client email always makes a quote Hot.

## AI Follow-Up Triage

For each quote you get an **AI Conclusion Summary** of the conversation and, where useful,
a **Suggested Email Snippet • Waiting for Approval**. You can edit it, type a manual reply
instead, and approve it to send. Sending clears the draft and marks the thread as
outgoing; the sent email is logged.

## Follow-up agents

For hands-off follow-up, managers can create autonomous follow-up agents (**Manage
Autonomous Follow-up Agents**). An agent has:

- a **name** and **agent email**;
- **core instructions** (product, policy, tone);
- an **importance level** (higher importance is processed first so a client is not flooded);
- a **follow-up frequency** (immediate, daily, every 3 days, weekly, or a number of days);
- a **specific task** (for example *Follow Up*, *Answer Questions*, *Negotiate Deal*);
- **action control** (whether it sends automatically or waits for manual control).

Assign quotes to an agent when you create them (**Assign Agent**) or later from the agent's
page (**Assign Quotes to Agent**). When a follow-up is due the agent writes and dispatches
it; **View Details & Logs** shows what it has done. Quotes with no agent stay on manual
follow-up.
