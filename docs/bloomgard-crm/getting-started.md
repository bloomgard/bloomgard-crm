# Getting started

## Signing in

- **Client portal** – `/login`. Your company's users sign in with email and password.
- **Platform admin ("Boss") portal** – `/boss/login`. For Bloomgard operators only; see [Platform admin](./platform-admin.md).

New users are created by a workspace Manager or Admin from **Settings → User Access**
(see [Settings](./settings.md)). A Manager can also issue a password reset for a user.

## Roles and what they see

| Role | Sees | Can do |
|---|---|---|
| **Admin / Manager** | Every quote in the workspace | Everything, plus user management, Master Data, field configuration, AI Settings, quote template. |
| **Agent (sales user)** | Only the quotes they created | Create and edit their own quotes, use Inbox and AI actions, set their own profile and forwarding address. |

## The workspace

The left sidebar has seven views plus the AI assistant:

1. **Dashboard** – totals, your contribution, recent activity, AI charts.
2. **Quotes** – the pipeline of quotations; create a new one from here.
3. **Inbox** – client email, AI actions, reply and compose.
4. **Follow ups** – quiet quotes scored Hot / Warm / Cold.
5. **Lead Gen** – enquiries that are not yet quotes.
6. **Docs** – the Document Library of generated quote PDFs.
7. **Settings** – a list of configuration screens.
8. **Bloomgard AI** – chat assistant over your data.

## First-day checklist for a workspace admin

1. **Settings → Your Profile**: set your full name, job title, phone (and optional sign-off). The AI signs replies with this.
2. **Settings → Master Data**: import or type your product catalogue.
3. **Settings → Email Settings**: set your personal forwarding address and set up forwarding in Gmail/Outlook ([Email setup](./email-setup.md)).
4. **Settings → AI Settings**: choose tone and add instructions ([AI assistant](./ai-assistant.md)).
5. **Settings → User Access**: add your team.
6. Create a test quote and send it to yourself.
